# TQF3 Week-to-Module Map

| module_id | weeks | tqf3_topics | why_this_grouping |
| --- | --- | --- | --- |
| limits-and-functions | 2 | limit theorem, one-sided limits, infinite limits, function behavior near a point | this is the first concept block and prepares continuity |
| continuity-and-applications | 3 | continuity at a point, continuity on an interval | continuity is a clean bridge from limits to later function analysis |
| differentiation | 4-10 | derivative definition, derivative rules, trigonometric/exponential/logarithmic derivatives, applications of derivatives, extrema, graphing, indeterminate forms, L'Hospital | these weeks form one extended derivative-and-application arc |
| integration | 11-14 | antiderivatives, indefinite integrals, substitution, Fundamental Theorem of Calculus, definite integrals, integration techniques | the integration arc begins after derivative applications are stable |

## Notes

- Week 15 is review and should support all modules rather than create a separate content module.
- Use this map to keep the module count aligned with the teaching plan.
