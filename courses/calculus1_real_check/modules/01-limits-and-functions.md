# Limits and Functions

Start with function behavior, limit ideas, and first ways to reason about approaching values.

## Learning Snapshot

- Learning pace: 2 week(s)
- Main CLO emphasis: CLO1, CLO2
- Module style: concept

## What You Will Explore

In this module, learners gradually work through limit theorem, one-sided limits, infinite limits, graph and function behavior near a point.

The main ideas you will revisit in this part of the course are:

- limit theorem, one-sided limits, infinite limits

## Learning Flow

- Week 2: limit theorem, one-sided limits, infinite limits

## Try While You Learn

- graph-reading warm-up, limit comparison cards, quick routine check

## Check Your Understanding

- limit explanation and short computation check
