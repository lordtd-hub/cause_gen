# Module Map

## CLO Overview

- CLO1: Explain the meaning of limits, continuity, derivatives, and integrals in standard first-course contexts.
- CLO2: Apply standard calculus techniques to compute limits, derivatives, and integrals.
- CLO3: Analyze functions and their behavior using continuity, derivatives, and definite integrals.
- CLO4: Use calculus reasoning to justify steps and interpret results in problem-solving situations.

## Module Overview

- 01. Limits and Functions | kind: concept | CLOs: CLO1, CLO2
- 02. Continuity and Applications | kind: application | CLOs: CLO1, CLO3
- 03. Differentiation | kind: application | CLOs: CLO2, CLO3, CLO4
- 04. Integration | kind: application | CLOs: CLO2, CLO3, CLO4
