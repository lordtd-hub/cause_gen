# Mission Framing: CLO3 / Complex Differentiation and Analytic Functions

## Mission Identity

- target_clo: `CLO3`
- module: `complex-differentiation`
- mission_family: `sbra-step-based-reasoning`
- bloom: `Apply`

## Evidence Target

- evidence type: `SBRA candidate`
- assessment role: `formative`
- badge hook: `clo3-analytic-function-strategist`

## Why This Mission Exists

- Learners should move beyond naming derivative facts and justify when a complex function should be treated as analytic or holomorphic.
- This mission should check whether learners connect derivative reasoning to the structure and conditions of the function instead of guessing from familiar examples.

## Misconceptions Worth Targeting

- assuming that any function with a symbolic derivative is automatically analytic everywhere
- treating complex differentiability as identical to ordinary real-variable differentiability
- choosing a result from memory without checking the conditions that support it
- explaining the answer without tying the reasoning back to the structure of the function

## Step Intent Draft

1. identify the function features and derivative target that the task is asking about
2. choose the analytic-function reasoning path that fits the structure and conditions
3. justify the final claim in a short argument that keeps the conditions visible
