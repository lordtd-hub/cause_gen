# Mission Framing: CLO2 / Search and Problem Solving

## Mission Identity

- target_clo: `CLO2`
- module: `search-and-problem-solving`
- mission_family: `sbra-step-based-reasoning`
- bloom: `Apply`

## Evidence Target

- evidence type: `SBRA candidate`
- assessment role: `formative`
- badge hook: `clo2-search-strategist`

## Why This Mission Exists

- Learners should move from naming search algorithms to selecting a strategy that fits the structure of a problem.
- This mission should check whether learners can justify a search choice with state-space and heuristic information instead of guessing from familiarity.

## Misconceptions Worth Targeting

- treating all search problems as identical without checking the state-space structure
- naming a search algorithm without explaining why it matches the problem
- assuming that a heuristic automatically guarantees the best answer
- focusing only on speed without checking completeness or fit to the goal

## Step Intent Draft

1. identify the state space, initial state, and goal condition of the problem
2. compare the relevant search strategies using the available structure and constraints
3. choose the best-fit strategy and justify the tradeoff in a short argument
