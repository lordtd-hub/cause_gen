# Intro to AI Course Design

## 3.1 Module Structure

| Module | Suggested Weeks | Main CLOs | Core Content |
| --- | --- | --- | --- |
| AI Foundations | 1-2 | CLO1, CLO4 | what AI is, intelligent agents, problem domains, terminology, early ethical questions |
| Search and Problem Solving | 3-5 | CLO2, CLO3 | state spaces, uninformed and informed search, heuristics, problem formulation |
| Knowledge and Reasoning | 6-8 | CLO2, CLO3 | knowledge representation, rules, logic, inference, introductory machine learning links |
| Intelligent Systems and Ethics | 9-15 | CLO1, CLO4 | neural networks, fuzzy logic, mini-project framing, system evaluation, ethics and responsible use |

## 3.2 Week-by-Week Plan

| Week | Theme | Suggested Interactive Materials | Main Evidence |
| --- | --- | --- | --- |
| 1 | introduction to AI, domains, and intelligent behavior | AI example sorting, terminology warm-up | concept explanation check |
| 2 | intelligent agents, scope of AI, and first ethical questions | case comparison cards, guided discussion | short reflection and terminology quiz |
| 3 | problem formulation and state-space representation | state-space board activity, graph task | worked problem setup |
| 4 | uninformed search and search-tree reasoning | BFS/DFS comparison cards, path tracing | search comparison check |
| 5 | heuristics and strategy choice | heuristic ranking activity, strategy justification | SBRA candidate on search choice |
| 6 | facts, rules, and representation | rule-base sorting, logic notation prompts | representation task |
| 7 | inference and reasoning chains | inference chain unpack, rule application sequence | reasoning analysis task |
| 8 | introductory machine learning as an AI approach | model-behavior discussion, simple coding review | method comparison note |
| 9-10 | neural-network ideas and intelligent-system examples | demo review, output interpretation | explanation task |
| 11 | fuzzy logic and alternative reasoning styles | fuzzy set activity, threshold comparison | concept check and mini analysis |
| 12-13 | mini-project development | project workshop, mentoring, peer review | project milestone evidence |
| 14 | project presentation and critique | presentation session, question prompts | rubric-based presentation |
| 15 | course reflection and AI ethics wrap-up | debrief discussion, reflective summary | ethics reflection and self-evaluation |
