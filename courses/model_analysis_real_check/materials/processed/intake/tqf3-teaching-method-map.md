# TQF3 Teaching Method Map

| source_method | activity_family | used_in | note |
| --- | --- | --- | --- |
| lecture | guided discussion | modeling-foundations | establish the language and purpose of mathematical models |
| lecture plus discussion plus activity | guided exploration | modeling-tools-and-techniques | compare techniques before moving into construction |
| lecture plus discussion plus activity | parameter play | linear-and-nonlinear-models | explore how assumptions shift model behavior |
| lecture plus discussion plus activity | guided exploration | model-development-and-probability | build and refine models in manageable stages |
| lecture plus discussion plus practice | theorem-condition diagnosis | validation-and-advanced-cases | inspect when validation logic is strong enough |
| project-based instruction | reflection | project-modeling-studio | use project work, peer review, and presentation as the capstone |
