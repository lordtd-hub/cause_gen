# Model Analysis Course Design

## 3.1 Module Structure

| Module | Suggested Weeks | Main CLOs | Core Content |
| --- | --- | --- | --- |
| Modeling Foundations | 1 | CLO1, CLO2 | course orientation, meaning of models, and why modeling matters |
| Modeling Tools and Techniques | 2-3 | CLO1, CLO3 | baseline mathematical and statistical tools for model work |
| Linear and Nonlinear Models | 4-5 | CLO3, CLO5 | compare structures and identify when different model forms are useful |
| Model Development and Probability Models | 6-9 | CLO3, CLO5 | fuller model construction, integration of ideas, and probability-oriented modeling |
| Validation and Advanced Cases | 10-12 | CLO2, CLO4, CLO6 | testing, checking, advanced cases, and ethical reasoning |
| Project Modeling Studio | 13-16 | CLO3, CLO4, CLO5, CLO6 | project-based model construction, review, presentation, and reflection |

## 3.2 Week-by-Week Plan

| Week | Theme | Suggested Interactive Materials | Main Evidence |
| --- | --- | --- | --- |
| 1 | orientation to mathematical modeling and why models matter | modeling-purpose prompts, first example discussion | concept explanation check |
| 2 | baseline modeling tools and mathematical techniques | technique sorting, worked example comparison | short review note |
| 3 | extending the modeling toolkit | assumptions checklist, peer explanation | technique-application task |
| 4 | linear versus nonlinear model structure | model comparison cards, structure-choice discussion | model comparison note |
| 5 | choosing a useful model form for a real problem | parameter and assumption prompts, interpretation check | design justification |
| 6-7 | staged model development | build-a-model workshop, guided refinement | draft model evidence |
| 8-9 | probability-oriented modeling | uncertainty prompts, output-comparison activity | interpretation task |
| 10 | validation and model checking | validation checklist, failure-mode discussion | validation plan |
| 11-12 | advanced examples and case studies | case study review, critique prompts | advanced-case note |
| 13-14 | project work | project planning, mentoring, peer review | project milestone evidence |
| 15 | project continuation and peer critique | critique session, revision notes | peer-review evidence |
| 16 | final project presentation and submission | presentation session, reflective debrief | project presentation evidence |
