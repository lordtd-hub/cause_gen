Active Learning ในบทนี้

แต่ละบทควรมีช่วงให้ผู้เรียนได้ลองคิด ลองสำรวจ หรือเช็กความเข้าใจระหว่างทาง ไม่ใช่อ่านเนื้อหาอย่างเดียว ส่วนนี้จึงบอกว่าบทนี้จะมีกิจกรรมหรือ interactive แบบไหนช่วยพยุงการเรียนบ้าง

✅ เช็กความเข้าใจระหว่างบท

หยุดตอบคำถามสั้น ๆ เพื่อดูว่าจับใจความสำคัญของบทได้แล้วหรือยัง

💡 sbra-sequence

กิจกรรม interactive ของบทนี้จะถูกเติมต่อในรอบ authoring

จุดเช็กระหว่างเรียน

ใช้ส่วนนี้หยุดเช็กความเข้าใจเป็นระยะ เพื่อไม่ให้การเรียนไหลไปเร็วเกินจนหลุดประเด็นสำคัญของบท

ย้อนดูนิยามหรือทฤษฎีบทหลัก

ก่อนอ่านต่อ ลองเช็กว่านิยามหรือทฤษฎีบทที่ใช้ในบทนี้มีเงื่อนไขสำคัญอะไรบ้าง

จับจุดของเหตุผล

ลองอธิบายให้ตัวเองฟังว่าตอนนี้กำลังพิสูจน์อะไร และเหตุผลแต่ละช่วงเชื่อมกันอย่างไร

ถ้ายังไม่มั่นใจให้ย้อนกลับไปทบทวน

ถ้ารู้สึกว่าบทนี้ยากเกินไป ให้ย้อนกลับไปดูหัวข้อก่อนหน้าของบทหรือบทก่อนหน้าได้เสมอ

ไปต่อจากบทนี้

หลังจากอ่านจบบทนี้แล้ว ผู้เรียนสามารถเลือกทางไปต่อได้ชัดเจน ทั้งการทบทวน การไปบทถัดไป หรือการลองทำภารกิจ

กลับไปดูแผนบทเรียน

ถ้าอยากมองภาพรวมอีกครั้งหรือเลือกบทอื่นก่อน ก็สามารถกลับไปที่หน้า lessons ได้เสมอ
