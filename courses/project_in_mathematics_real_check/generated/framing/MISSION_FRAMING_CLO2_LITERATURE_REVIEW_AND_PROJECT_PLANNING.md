# Mission Framing: CLO2 / Literature Review and Project Planning

## Mission Identity

- target_clo: `CLO2`
- module: `literature-review-and-project-planning`
- mission_family: `sbra-step-based-reasoning`
- bloom: `Analyze`

## Evidence Target

- evidence type: `SBRA candidate`
- assessment role: `formative`
- badge hook: `clo2-analyze-readiness`

## Why This Mission Exists

- Learners should not move into project execution without showing that they can compare related work and justify a project direction.
- This mission should diagnose whether the learner can separate a feasible project issue from a merely interesting topic.

## Misconceptions Worth Targeting

- choosing a project direction only because the topic feels interesting, without checking evidence or feasibility
- treating one familiar article as enough related work to define the whole project
- mixing up source collection with actual issue analysis
- giving a project title without explaining the decision path that led to it

## Step Intent Draft

1. identify what makes a proposed project issue academically usable
2. compare candidate sources and decide which evidence is strong enough to support the project direction
3. test whether the proposed project direction still matches available time, scope, and advisor guidance
4. close with a justified project-direction statement rather than a loose topic label
