# Project in Mathematics Course Design

## 1. Course Direction

- Course code: `SMA6002`
- Course name: `Project in Mathematics`
- Course style: project-based, advisor-guided, presentation-heavy
- TQF3 source anchor: `tqf3-project-in-mathematics.md`

## 2. CLO Summary

| CLO | Bloom | Short Meaning |
| --- | --- | --- |
| CLO1 | Understand | search for relevant sources and ideas |
| CLO2 | Analyze | analyze related work to define a project direction |
| CLO3 | Apply | design a suitable project process |
| CLO4 | Evaluate | present progress and findings clearly |
| CLO5 | Apply | work with discipline and professionalism |

### 3.1 Module Structure

| Module | Suggested Weeks | Core Content | Main CLOs |
| --- | --- | --- | --- |
| Project Scoping and Advisor Alignment | 1 | topic selection, feasibility of ideas, advisor matching, early project framing | CLO1, CLO2 |
| Literature Review and Project Planning | 2-4 | source search, related work analysis, proposal shaping, project planning, database use | CLO1, CLO2, CLO3 |
| Project Execution and Progress Review | 5-10 | progress review, project execution, consultation cycle, project logs, evidence recording | CLO3, CLO4, CLO5 |
| Report Writing and Seminar Presentation | 11-15 | report writing, abstract and report structure, seminar presentation, final submission | CLO4, CLO5 |
