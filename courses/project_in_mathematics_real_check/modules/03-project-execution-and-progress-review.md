# Project Execution and Progress Review

Carry out the project with advisor consultation, evidence logging, and progress reporting.

## Learning Snapshot

- Learning pace: 5-10 week(s)
- Main CLO emphasis: CLO3, CLO4, CLO5
- Module style: project

## What You Will Explore

In this module, learners gradually work through progress review, project execution, consultation cycle, project logs, evidence recording.

The main ideas you will revisit in this part of the course are:

- first progress presentation
- project execution and evidence logging
- second progress presentation and early result review

- Week 8: project execution and evidence logging
