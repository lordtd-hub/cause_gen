# Report Writing and Seminar Presentation

Prepare the final report, refine communication, and present the project in seminar form.

## Learning Snapshot

- Learning pace: 11-15 week(s)
- Main CLO emphasis: CLO4, CLO5
- Module style: communication

## What You Will Explore

In this module, learners gradually work through report writing, abstract and report structure, seminar presentation, final submission.

The main ideas you will revisit in this part of the course are:

- full report structure and abstract writing
- final report completion
- seminar presentation
- final submission and closing reflection

## Learning Flow

- Week 11: full report structure and abstract writing
- Week 12: full report structure and abstract writing
- Week 13: final report completion
- Week 14: seminar presentation
- Week 15: final submission and closing reflection

## Try While You Learn

- report writing workshop
- individual review and checklist
- rehearsal seminar and peer Q&A
- final checklist and self-reflection

## Check Your Understanding

- report draft section review
- near-final report package
- seminar presentation performance
- final report and professionalism evidence
