Literature Review and Project Planning

Search, evaluate, and synthesize relevant sources to frame a project direction and plan.

Learning Snapshot

  • Learning pace: 2-4 week(s)
  • Main CLO emphasis: CLO1, CLO2, CLO3
  • Module style: analysis

What You Will Explore

In this module, learners gradually work through source search, related work analysis, proposal shaping, project planning, database use.

The main ideas you will revisit in this part of the course are:

  • project planning and source search
  • related work analysis and proposal shaping
  • planning steps, timeline, and proposal refinement

Learning Flow

  • Week 2: project planning and source search
  • Week 3: related work analysis and proposal shaping
  • Week 4: planning steps, timeline, and proposal refinement

Try While You Learn

  • database exploration, source-quality checklist
  • small-group case analysis, proposal workshop
  • planning template workshop, peer feedback

Check Your Understanding

  • search notes and source shortlist
  • related-work analysis and draft problem statement
  • project plan and revised proposal

Active Learning ในบทนี้

แต่ละบทควรมีช่วงให้ผู้เรียนได้ลองคิด ลองสำรวจ หรือเช็กความเข้าใจระหว่างทาง ไม่ใช่อ่านเนื้อหาอย่างเดียว ส่วนนี้จึงบอกว่าบทนี้จะมีกิจกรรมหรือ interactive แบบไหนช่วยพยุงการเรียนบ้าง

✅ เช็กความเข้าใจระหว่างบท

หยุดตอบคำถามสั้น ๆ เพื่อดูว่าจับใจความสำคัญของบทได้แล้วหรือยัง

🧩 คลี่นิยามทีละส่วน

แยกนิยามหรือเงื่อนไขสำคัญออกเป็นชิ้น ๆ เพื่อมองความหมายได้ชัดขึ้น

🪜 ไล่ขั้นตอนการคิด

เหมาะกับโจทย์ที่ต้องค่อย ๆ เห็นลำดับการคิดก่อนจะไปถึงคำตอบหรือข้อพิสูจน์

จุดเช็กระหว่างเรียน

ใช้ส่วนนี้หยุดเช็กความเข้าใจเป็นระยะ เพื่อไม่ให้การเรียนไหลไปเร็วเกินจนหลุดประเด็นสำคัญของบท

ระบุวัตถุที่กำลังศึกษา

ลองเช็กว่าตอนนี้กำลังมองชุด ลำดับ ฟังก์ชัน หรือพารามิเตอร์ชนิดใดอยู่

ลองดูการเปลี่ยนแปลง

ใช้กิจกรรม interactive เป็นตัวช่วยดูว่าเมื่อเงื่อนไขเปลี่ยน ผลลัพธ์หรือพฤติกรรมเปลี่ยนอย่างไร

สรุปด้วยภาษาของตัวเอง

หลังเรียน ลองพูดใจความสำคัญของหัวข้อนี้ด้วยภาษาของตัวเอง ไม่ยึดติดกับสูตรหรือสัญลักษณ์อย่างเดียว

ไปต่อจากบทนี้

หลังจากอ่านจบบทนี้แล้ว ผู้เรียนสามารถเลือกทางไปต่อได้ชัดเจน ทั้งการทบทวน การไปบทถัดไป หรือการลองทำภารกิจ
