# Tmp Skill Test

This course is a lightweight sandbox used to test shared workflow and skill behavior.

## Read First

1. `generated/workflow/README_FIRST.md`
2. `generated/workflow/CURRENT_TASK.md`
3. `generated/workflow/DECISION_LOG.md`
4. `course.config.json`

## Folder Guide

- `course.config.json`
  Final learner-facing course identity, badges, modules, and CLO labels for the sandbox course.
- `materials/raw/`
  Raw source test files.
- `materials/processed/`
  Intake artifacts and temporary source material.
- `generated/`
  Workflow logs and test notes.
- `modules/`
  Module markdown source.
- `missions/`
  Runtime mission data.
- `resources/`
  Runtime resource manifest.

## Editing Rule

- Keep this course simple and use it only for shared workflow checks
- Do not patch output files directly
