# Assessment Evidence Bridge Examples

This document records the accepted baseline for the bridge:

`Assessment Evidence Map -> Mission Framing -> missions/missions.json`

Its purpose is to show how the bridge should be used before item-level problem-bank work begins.

## Practical Rule

If a course starts from `TQF3` and does not yet have a mature item-level problem pool:

1. prepare the `Assessment Evidence Map`
2. write mission framing files only for strong candidates
3. compile accepted framing into `missions/missions.json`
4. deepen item-level mission content later

Do not skip straight from `TQF3` into item-level mission writing unless the source already contains strong item-ready material.

## Acceptance Rule

Treat this bridge as `baseline accepted` when:

- the evidence map is specific enough to identify mission direction
- the framing file is specific enough to shape a real runtime draft
- the runtime mission JSON can be generated without inventing a new schema

Reopen the bridge only if a later real-course run shows that it still cannot support the intended mission nature.
