# Teaching Method Map

Use this file to translate TQF3 teaching-method wording into reusable active-learning families before deep activity writing begins.

## Law

- This file is not a lesson script.
- This file must connect `source method + learning intent + module + activity family + placeholder target`.
- If this file does not exist yet, do not jump directly into detailed active-learning prose for modules.

## Table

| Source Method | Learning Intent | Linked Modules | Activity Family | Placeholder Target | Notes / Gaps |
| --- | --- | --- | --- | --- | --- |
| lecture plus guided discussion | build shared concepts and surface misconceptions | module-1, module-2 | guided discussion | intro-how-we-learn | keep learner-facing wording light |
| proof demonstration and guided proof practice | build proof fluency and theorem-condition awareness | module-3 | proof practice | module-active-learning | still needs concrete prompts later |
| problem-based learning | make learners choose and justify a method | module-4 | theorem-condition diagnosis | module-active-learning | real task not written yet |

## Notes

- Use one row per teaching method or clearly distinct teaching move.
- Repeat rows if one source method feeds multiple modules in different ways.
- Keep `Activity Family` inside the current baseline family names unless real-course testing fails.
